# Mobile Shop POS – releases

Installers and updates for Mobile Shop POS. Download the latest installer from the
[Releases](https://github.com/zawibuttar/mobile-shop-releases/releases/latest) page:

- Windows: `MobileShopPOS-<version>-setup.exe`
- Mac (Intel): `MobileShopPOS-<version>-x64.dmg` · Mac (Apple Silicon): `MobileShopPOS-<version>-arm64.dmg`

Installed copies check this repository for updates on launch.
